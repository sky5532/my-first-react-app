# My First React App

A small interactive React application built for the BeTechified Advanced Class assignment, "React Basics – Your First Interactive App".

## Description

**Live demo:** https://sky5532.github.io/my-first-react-app/

The app demonstrates functional components, JSX, state, events and conditional rendering. It includes:

- A counter with Increase, Decrease and Reset buttons
- An "Even number" / "Odd number" message that updates with the counter
- A name input that shows a personalized greeting (only when the input is not empty)
- A greeting in a lighter shade of red
- A footer showing the current year

## Built With

- React
- Vite
- CSS

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/sky5532/my-first-react-app.git
   ```
2. Go into the project folder:
   ```bash
   cd my-first-react-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the link shown in the terminal (usually http://localhost:5173).
